# git

个人代码仓库，用于保存和同步本地项目。

## 克隆

```bash
git clone https://github.com/myna27/git.git
```

## 目录结构

```
.
├── README.md      # 项目说明
└── .gitignore     # 忽略规则
```

## 常用命令

```bash
git status              # 查看改动
git add .               # 暂存全部改动
git commit -m "说明"    # 提交
git push                # 推送到 GitHub
```
